# CadenceFlow Handoff Package

Start here when resuming development.

1. `PROJECT_STATUS.md` — current implementation state, verification, known issues, next sequence.
2. `NEXT_DEVELOPER_TASK.md` — exact next assignment (US5 Batch A, T077–T080).
3. `DEVELOPMENT_WORKFLOW.md` — developer submission and orchestrator review protocol.
4. `specs/001-cadenceflow-core-studio/spec.md` — approved product requirements.
5. `specs/001-cadenceflow-core-studio/tasks.md` — task ledger; T001–T076 are complete.
6. `specs/001-cadenceflow-core-studio/plan.md` — implementation architecture.
7. `specs/001-cadenceflow-core-studio/data-model.md` — canonical model.
8. `specs/001-cadenceflow-core-studio/contracts/` — portable project and provider contracts.
9. `reference/cadenceflow.html` — authoritative original prototype/reference.

The package intentionally contains no `node_modules`, no Git history, and no production piano sample bank.
