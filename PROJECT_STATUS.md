## Technical decisions to preserve

- Matrix is for harmonic discovery; My Progression owns temporal editing. A Matrix card is a template, not a Step. Preview/audition must not cause Project/history mutations or autosave; the existing selection-only route remains persisted and may have an earlier autosave pending. Each valid Apply creates exactly one mutating command/history entry. Duration resize uses an absolute timeline endpoint and exact Rational duration, not screen coordinates.
- Print is a projection of existing Project/measure layout, not a second score or persisted state. Staff, audio, MIDI, and MusicXML continue to project the same canonical Steps.
- T199 evaluated ryohey/signal at commit `632de9685990c90d0be127994908cc43692ff82a` under its pinned MIT LICENSE but copied no donor code. Its gesture adapter is original, transient test code; no Signal store/history/audio/tick model enters production and no `THIRD_PARTY_NOTICES.md` is needed for this spike. Future adaptation still requires per-file provenance and notices before code lands.
- T200 label hierarchy is local UI state and does not change Project/schema v6. Quick Edit shares the canonical selected Step ID with the existing Inspector; it must remain aligned with the selected score system, including under CSS zoom, rather than sitting after all systems or overlaying the notation.
- T201 derives exact resize candidates from the existing timeline and measure layout. The gesture snapshot is keyed by Project identity and Step ID so pointer movement does not rebuild every Step's candidate lattice. A resize commits one canonical command; Rest steps have no handle.
- Global engine/tone selection belongs only to AudioEnginesInspector. Track-local instrument, volume, Mute/Solo, status, and retry remain separate.
- The pinned Salamander source revision 370497372ece1603d1ca7b9892c82c1da566565e identifies Alexander Holm and CC BY 3.0; the distributed public/licenses/piano-hq-attribution.txt names the source, derivative preparation, and license URI.
