# Piano Roll group note selection and editing handoff

## Result

Implemented transient, owner-scoped Melody selection and group editing for the Piano Roll. Measure, System, and Progression scopes drive contextual Ctrl/Cmd+A; the named selection buttons remain independent. The common `My Progression` heading provides the Progression scope target, with no extra reset button. The selection help is a dismissible hover/focus infotip.

Group movement, Delete, Copy, Cut, Paste, and Duplicate operate on the selected Melody owners through the authored-melody transaction path. Clipboard timing uses exact Rational offsets and concert pitches. Paste plans include any needed tail materialization and appended Measures in the same transaction. Selection and clipboard remain transient. Signal was used as behavioral reference only; no Signal code was copied.

An ordinary completed note click auditions exactly one effective Melody event using the existing concert-pitch/instrument projection and current Melody Track volume. Shift-additive clicks, cancelled drags, and group operations remain silent; a delayed prepare is ignored after the Piano Roll view changes. Paste extends to a full barline as needed, but refuses atomically if extending the composition would expose or lengthen old raw Melody that was not effective before the paste.

This is a developer handoff, not independent root acceptance. Existing unrelated dirty work remains in the checkout and was preserved.
